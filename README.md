The contactless temperature scanner with voice output is a smart and efficient system designed to measure human 
body temperature without any physical contact. This project aims to provide a safe, fast, and user-friendly solution 
for temperature monitoring, especially in public places where large numbers of people need to be screened. The system uses 
an infrared temperature sensor to accurately measure body temperature and an ultrasonic sensor to detect the presence of a person, ensuring automatic operation 
without manual intervention.
The microcontroller processes the collected data in real time and compares it with a predefined threshold value to determine whether the temperature is normal 
or abnormal. Based on the result, a voice module provides appropriate audio feedback through a speaker, enhancing usability and accessibility for all users. 
This reduces the need for visual displays and makes the system suitable even for non-technical individuals.
The system is cost-effective, portable, and easy to implement, making it ideal for use in hospitals, schools, offices, and other public areas. It helps 
in minimizing human contact and reducing the risk of infection spread, especially during health emergencies like COVID-19. Overall, the project demonstrates 
a reliable and practical approach to contactless temperature monitoring with improved user interaction.
